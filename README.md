# My-Portfolio Website

Personal portfolio of Pulkit Shubham, built with Vite, React, Tailwind CSS v4, Motion and Lenis.

## Scripts

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
npm run preview  # serve the production build
```

## Editing content

All text, skills, education and projects live in `src/data/content.js`. Images and the CV are served from `public/`.

The previous Create React App version lives in the git history before the redesign commit.
